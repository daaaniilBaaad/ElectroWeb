# ElectroWeb – система продаж электроники

## Описание проекта
ElectroWeb – это веб-приложение для управления сетью продаж электроники с иерархической структурой. Система представляет собой REST API с админ-панелью для управления звеньями сети (заводы, розничные сети, индивидуальные предприниматели).

Каждое звено сети содержит контактную информацию, список продуктов и информацию о поставщике. Реализована автоматическая иерархия уровней: завод находится на уровне 0, остальные звенья получают уровень на основе отношения к поставщику.

## Используемые технологии
- Python 3.13
- Django 6.0
- SQLite
- Django REST Framework
- django-filter

## Архитектура проекта
- `models.py` – модели NetworkNode и Product
- `views.py` – ViewSet'ы для API
- `serializers.py` – сериализаторы DRF
- `admin.py` – конфигурация админ-панели

## Функциональность
- Иерархическая структура сети (завод → розничная сеть → ИП)
- Автоматический расчёт уровня в иерархии
- Админ-панель с полным управлением
- REST API с CRUD операциями
- Фильтрация по стране
- Защита поля "Задолженность перед поставщиком" от изменения через API
- Права доступа: только активные сотрудники

## API
- `GET /api/nodes/` – список звеньев сети
- `POST /api/nodes/` – создание звена
- `GET /api/nodes/{id}/` – детали звена
- `PUT /api/nodes/{id}/` – обновление звена
- `DELETE /api/nodes/{id}/` – удаление звена
- `GET /api/products/` – список продуктов
- `GET /api/nodes/?country=Россия` – фильтрация по стране

## Установка и запуск

```
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
